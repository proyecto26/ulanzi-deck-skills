**Configure Ulanzi stream controllers from your AI agent.** Describe the keys you want ("a coding
page with Claude, VS Code and the terminal, and a streaming page with OBS live/record buttons")
and the agent builds the whole Ulanzi Studio profile: launchers resolved for your OS, websites,
hotkeys, media and OBS keys, pages and folders, consistent key art, and a preview image to approve
before anything touches the device. Applying makes an automatic backup and can be rolled back.

Works with the **D200H "Deck Dock"** (verified) and the Ulanzi Studio family (D200, D200X, Dial)
on **Windows** and **macOS**, with guidance for **Linux**.

## Quick Start

### Installation

This plugin follows the [Agent Plugins](https://agent-plugins.org/) v1.0.0 packaging standard
(root [`plugin.json`](./plugin.json)) and its skill follows the [Agent Skills](https://agentskills.io/)
spec (`skills/ulanzi-deck/SKILL.md`, self-contained). It also ships Claude Code manifests
(`.claude-plugin/`) and an OpenAI Codex manifest (`.codex-plugin/`).

#### Option 1: Claude Code plugin (recommended)

```bash
/plugin marketplace add proyecto26/ulanzi-deck-skills
/plugin install ulanzi-deck-skills
```

#### Option 2: Skills CLI (any agent: Claude Code, Codex, Cursor, Copilot CLI, ...)

Codex, Cursor and Copilot CLI can also install the repository as a plugin through the manifests it
ships (`.codex-plugin/plugin.json`, `.agents/plugins/marketplace.json`, root `plugin.json`); follow
your host's "add plugin from GitHub" flow with `proyecto26/ulanzi-deck-skills`.

```bash
npx skills add proyecto26/ulanzi-deck-skills
```

#### Option 3: Clone and copy

```bash
git clone https://github.com/proyecto26/ulanzi-deck-skills.git
cp -r ulanzi-deck-skills/skills/ulanzi-deck ~/.claude/skills/
```

### Requirements

- [Ulanzi Studio](https://www.ulanzi.com/pages/ulanzi-app) (Windows 10+ or macOS 12+) and the device connected once.
- [uv](https://docs.astral.sh/uv/) (recommended: it provides Python dependencies automatically) **or** Python 3.10+ with `pip install pillow`.

### First run

Just ask your agent:

> *"Set up my Ulanzi D200H with a Dev page (Claude, VS Code, terminal, GitHub) and a Stream page with OBS go-live and record buttons. Show me the preview first."*

## Features

| | |
|---|---|
| **Portable layouts** | One small JSON file describes a profile. Apps are referenced by name (`"app": "OBS Studio"`) and resolved per OS: Start Menu shortcuts and Store apps on Windows, `.app` bundles on macOS. |
| **Key art** | Generated 196x196 keys with brand colors, the app's real icon, or any of 2,000+ Material Icons glyphs, plus a preview sheet of every page. |
| **Safe apply** | Backs up the whole Ulanzi data folder, writes the new profile completely before removing the one it replaces, restarts the app, and only reports OK when the app re-saves (accepts) the profile. `restore` rolls back. |
| **Edit what you have** | `export` turns any existing profile into an editable layout, keeping action parameters, every state image and app-drawn titles, and replacing machine paths with portable app names. Stock profiles are copied (`--name`) rather than overwritten. Knob (encoder) actions on D200X/Dial are not carried yet, so those models stay read-only. |
| **OBS** | Go live, record, virtual camera, replay buffer, scenes via Ulanzi Studio's OBS integration (needs OBS WebSocket). |
| **Reviewable** | Before approving, the agent shows the preview *and* what each key does; risky actions (typing text with Enter, raw actions, unusual URL schemes, scripts) are flagged, so a layout someone else wrote cannot hide behind a friendly icon. |
| **Honest about gaps** | macOS paths and formats are discovered and calibrated before writing; Linux users are pointed to community tools (OpenDeck + a D200/D200H plugin) instead of a promise. |

## How it works

Ulanzi Studio stores each profile as JSON plus PNG key images in its data folder
(`%APPDATA%\Ulanzi\UlanziDeck` on Windows). The skill ships one cross-platform tool:

```bash
uv run skills/ulanzi-deck/scripts/ulanzi.py state                       # what's installed, devices, profiles, backups
uv run skills/ulanzi-deck/scripts/ulanzi.py find-apps --filter obs      # launch targets on this OS
uv run skills/ulanzi-deck/scripts/ulanzi.py export -o my.json           # current profile -> editable layout
uv run skills/ulanzi-deck/scripts/ulanzi.py build --layout my.json      # validate + render key art + preview.png
uv run skills/ulanzi-deck/scripts/ulanzi.py apply --layout my.json      # backup, write, activate, verify
uv run skills/ulanzi-deck/scripts/ulanzi.py restore --backup <dir>      # roll back
```

The agent follows [`SKILL.md`](skills/ulanzi-deck/SKILL.md): orient with `state`, write the layout,
**show the preview and wait for your OK**, apply, then show a screenshot of the app.

## Platform support

| | Windows | macOS | Linux |
|---|---|---|---|
| Ulanzi Studio | yes | yes | no official app |
| Build layouts + previews | yes | yes | yes |
| Apply profiles | verified (Ulanzi Studio 3.4, D200H) | after a one-time calibration (`--force-unverified`) | no; use the community tools in [platforms.md](skills/ulanzi-deck/references/platforms.md) |

## Project structure

```
ulanzi-deck-skills/
├── plugin.json                    # Agent Plugins 1.0 manifest (Cursor, Copilot CLI)
├── .claude-plugin/                # Claude Code plugin + marketplace manifests
├── .codex-plugin/plugin.json      # OpenAI Codex manifest
├── .agents/plugins/marketplace.json
├── skills/ulanzi-deck/            # the skill (self-contained)
│   ├── SKILL.md
│   ├── scripts/ulanzi.py          # cross-platform CLI (PEP 723 header for uv)
│   ├── scripts/win/*.ps1          # Windows helpers: icons, app discovery, screenshot, installer
│   ├── references/                # layout schema, on-disk format, platforms, integrations
│   └── assets/                    # Material Icons font, glyph sheet, example layout
├── evals/                         # skill-creator eval prompts + assertions
├── tests/                         # offline unit tests (no device needed)
└── scripts/                       # check-manifests.sh, test-skill.sh
```

## Development

```bash
bash scripts/test-skill.sh          # offline tests (uses uv if present)
bash scripts/check-manifests.sh     # manifest consistency, privacy scan, claude plugin validate, schema
```

Skill quality is evaluated with Anthropic's skill-creator: prompts and assertions live in
[`evals/evals.json`](evals/evals.json); run outputs go to `skills/ulanzi-deck-workspace/` (git-ignored).

## Safety notes

- The skill has the agent show the preview and the key list and wait for your OK before `apply`
  (the CLI itself does not prompt, so the same applies if you run it by hand).
- Every apply makes a full backup; old backups are only deleted when you say so.
- Ulanzi Studio's optional AI-agent status monitor edits your agents' config files; the skill
  explains exactly what changes and asks first.
